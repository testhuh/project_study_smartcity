SmartCity 회의실 예약 자동화

Playwright 기반 브라우저 자동화 · Tkinter GUI 실행 환경

매번 사내 시스템에 직접 들어가 반복하던
회의실 예약 작업을 자동화하고,
GUI로 누구나 쉽게 실행할 수 있도록 구성했습니다.

🔄 자동화 흐름
①
GUI 정보 입력
▼
Tkinter GUI에서 날짜·시간·회의실·위치·회의명을 입력하면 JSON payload로 변환되어 실행 엔진에 전달됩니다.
②
AD 자동 로그인
▼
.env에 저장된 사내 AD 계정 정보로 SmartCity에 자동 로그인하고, 실패 시 수동 로그인 대기로 전환합니다.
③
회의실 검색 및 슬롯 탐색
▼
선택한 날짜·위치로 검색 후, 예약 가능한 시간 셀을 찾아 회의실 ID·승인유형 등 예약 파라미터를 추출합니다.
④
예약 정보 자동 입력
▼
추출한 파라미터로 예약 생성 페이지에 진입해 회의명·시간을 입력하고, 예약자 본인 체크까지 자동으로 처리합니다.
⑤
예약 실행 및 결과 확인
▼
예약 버튼 클릭과 확인 알림창 자동 처리 후, 목록 화면으로 돌아가 실제 반영 여부를 스크린샷으로 검증합니다.
🏆 주요 내용
✓
Playwright 브라우저 자동화 구현
▼
로그인부터 검색, 입력, 예약, 결과 확인까지 전체 과정을 실제 브라우저 동작으로 제어했습니다.
✓
사내 시스템 UI 변동 대응 로직
▼
날짜가 오늘로 되돌아가는 문제, 회의실 행 텍스트가 조금씩 다른 문제 등을 다단계 fallback 탐색으로 해결했습니다.
✓
.env 기반 인증 정보 분리
▼
AD 계정 정보를 코드와 분리해 안전하게 관리하고, 여러 경로에서 .env를 탐색하도록 구성했습니다.
✓
Tkinter GUI 실행 환경 구성
▼
입력 패널, 실행 통계 카드, 실시간 로그, 예약현황·취소 기능까지 갖춘 단독 실행형 GUI를 구현했습니다.
✓
GUI ↔ 자동화 엔진 연동 구조
▼
subprocess + stdin/stdout JSON 통신으로 GUI와 Playwright 엔진을 분리해, 둘 중 하나만 수정해도 안전하게 동작하도록 설계했습니다.
✓
예약 현황 조회 / 취소 기능
▼
내 예약 목록을 표 형태로 자동 파싱해 보여주고, 선택한 예약을 취소까지 진행할 수 있는 흐름을 구성했습니다.
